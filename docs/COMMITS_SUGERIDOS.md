# Historial de commits sugerido

El proyecto entregado ya incluye un historial local de commits. Para continuar mostrando un proceso de desarrollo real, usa mensajes como:

```text
feat: agregar nuevo documento de conocimiento
feat: mejorar recuperación de preguntas académicas
fix: corregir validación de preguntas vacías
docs: incluir enlace y captura del despliegue OCI
test: ampliar pruebas de búsqueda por sinónimos
```

Antes de enviar, agrega al menos un commit propio con la evidencia del despliegue:

```bash
git add README.md docs/evidencias/
git commit -m "docs: agregar evidencia de despliegue en OCI"
git push
```
