# Evidencias

Después del despliegue agrega aquí:

- `oci-app.png`: captura de la interfaz abierta desde la IP o dominio público de OCI.
- `oci-container.png`: captura opcional de la instancia de contenedor en estado **Active**.

Las capturas deben ocultar claves, tokens, OCID sensibles y cualquier dato privado.
